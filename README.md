# SliceBridge

**Bridge your prints.**

[English](#english) · [עברית](#hebrew)

<a id="english"></a>
## English

A 3D project shouldn't have to be rebuilt for every printer. **SliceBridge** connects Bambu Studio 3MF projects with supported printers and slicers. Choose your targets, convert locally using compatible printer profiles, and continue in the slicer you already know — without changing the original file.

I put SliceBridge together using existing solutions and AI assistance, adapted to fit my workflow. Hopefully it will be useful to others too.

**Conversion targets:** Snapmaker U1, Flashforge Creator 5, ELEGOO Centauri Carbon 2 (CC2) and QIDI Plus5 / X-Plus 5. The 603-model catalogue is reference metadata, not 603 supported conversion targets.

**MakerWorld connection:** SliceBridge provides a user-confirmed, guided beta extension setup; no browser-store extension is officially published yet. [Installation instructions](browser-extension/INSTALLATION.md).
