# Privacy / פרטיות

_Last reviewed: 19 October 2026. Scope: public project website and GitHub support channels._

## English

The [SliceBridge project website](https://nocturney.github.io/slicebridge/) is a static GitHub Pages site. It does not provide logins, accept 3MF files or collect information through an application form. The website code does not intentionally set analytics cookies, embed tracking pixels or load third-party analytics scripts.

**Hosting:** GitHub Pages hosts the website and may process IP addresses, connection data and server logs under [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Following links to GitHub is governed by GitHub's policies.

**Support:** GitHub issues and pull requests are public unless GitHub explicitly presents a private reporting flow. Avoid sharing personal or customer data, private model files or tokens. Security reports should use the private method described in [SECURITY.md](SECURITY.md).

**Desktop app:** This document does **not** certify the desktop application's complete data-handling behavior. The intended workflow is local-first, but the application, browser extension and update checks require a separate verified privacy review before general distribution. We will update this notice when that review is complete.
