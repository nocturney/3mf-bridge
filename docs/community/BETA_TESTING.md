# SliceBridge — testing a community build

This is a small open-source project. Anyone trying an experimental build can help with a quick report; there's no application form or formal tester programme.

## English

1. Try a simple, non-sensitive 3MF project and keep the original.
2. Note your OS, source/target slicers and printer model. Check whether the output converts, opens and slices.
3. Before physically printing, check the real nozzle, material, temperatures and build volume in the target slicer. A physical print is **optional**.
4. [Tell us what worked or didn't](https://github.com/nocturney/slicebridge/issues/new?template=beta_test.yml). Please don't upload private models, credentials or customer files.

A printer listed in a catalogue is not necessarily a printer that's been physically tested.
